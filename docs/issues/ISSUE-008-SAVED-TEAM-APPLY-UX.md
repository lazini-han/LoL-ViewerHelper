# ISSUE-008: 저장된 팀 불러오기 방식 개선 (드래그 대체)

작성일: 2026-10-25
상태: **구현 완료** (2026-10-25, 추천안 A + D)

---

## 1. 문제

팀 설정 페이지에서 저장된 팀을 팀 카드(팀 A / 팀 B)로 **드래그해서 드롭**해야만 적용된다.

- **좁은 가로폭(768px 이하)**: 팀 A·B 카드가 세로로 쌓이고 저장된 팀 목록은 그 아래에 있다. 드롭 대상이 화면 위쪽 밖에 있어 드래그 중에 스크롤해야 하는데, HTML5 드래그 중에는 스크롤이 거의 되지 않는다. 롤드컵 팀을 불러와 목록이 길어지면 더 멀어진다.
- **터치 기기**: HTML5 드래그앤드롭(`draggable`, `dragover`, `drop`)은 모바일 브라우저 지원이 불완전해 사실상 동작하지 않는다.
- **데스크톱에서도**: 잘 놓으려면 정확한 마우스 이동이 필요하고, 드래그가 된다는 안내가 없어 기능을 찾기 어렵다.

관련 코드: `js/pages/TeamSetupPage.js` 의 `createSavedTeamItem()`, `attachDragEvents()`

## 2. 개선 방안 비교

| 안 | 내용 | 좁은 폭/터치 | 작업량 | 비고 |
|----|------|:---:|:---:|------|
| **A. 팀 아이템에 `A` `B` 버튼** | 저장된 팀마다 `→A` `→B` 작은 버튼. 누르면 즉시 해당 팀에 적용 | ✅ | 작음 | 한 번 탭으로 끝. 스크롤 불필요 |
| B. 팀 카드에 불러오기 선택 상자 | 팀 카드 헤더에 `저장된 팀 불러오기 ▾` select. 고르면 적용 | ✅ | 작음 | 카드 안에서 해결. 팀이 많으면 목록이 길어짐. 리그 태그 표시 불가 |
| C. 선택 후 대상 탭 | 저장된 팀을 탭해서 선택 → 팀 카드를 탭 | △ | 중간 | 두 단계, 여전히 위로 스크롤 필요 |
| D. 드래그 중 자동 스크롤 | 화면 위·아래 가장자리 근처에서 드래그하면 페이지 자동 스크롤 | △ (데스크톱만) | 작음 | 터치는 여전히 안 됨 |
| E. 터치 드래그 직접 구현 | 포인터 이벤트로 드래그를 새로 구현 | ✅ | 큼 | 스크롤과 충돌, 유지보수 부담 |

## 3. 추천: A + D (드래그는 유지)

1. **저장된 팀 아이템에 `A` `B` 적용 버튼 추가** (주 방식)
   - 이름 옆, 삭제 `×` 앞에 배치. 각 버튼은 팀 A·B 진영색(파랑·빨강) 테두리로 구분한다.
   - 누르면 `state.applySavedTeam(teamId, 'blueTeam' | 'redTeam')` 후 다시 렌더링한다. 기존 드롭과 같은 함수다.
   - 툴팁(`title`): `팀 A에 불러오기` / `팀 B에 불러오기`
2. **적용 결과 확인**: 좁은 폭에서는 적용한 팀 카드가 화면 밖일 수 있다.
   - 적용된 카드를 잠시 강조 표시(테두리 반짝임)한다.
   - 카드가 화면 밖이면 그 카드로 부드럽게 스크롤한다. 연속으로 불러오는 경우가 있으므로, 이 동작은 4장에서 확인한다.
3. **기존 드래그 유지 + 가장자리 자동 스크롤**: 데스크톱 사용자는 지금처럼 드래그할 수 있다. 드래그 중 화면 위 가장자리(약 60px)에 가까워지면 페이지를 자동 스크롤해 좁은 창에서도 위쪽 카드에 놓을 수 있게 한다.
4. **안내 문구**: 목록 상단에 `A·B 버튼을 누르거나 팀 카드로 끌어다 놓으세요` 힌트를 작게 표시한다.
5. 글자색은 밝은 색만 사용한다. 데스크톱·375px 폭에서 브라우저 테스트하고 글자 대비 검사도 한다.

## 4. 확인이 필요한 사항

1. 추천안(A + D)으로 진행할지, B(카드 안 select)도 함께 넣을지
2. 버튼을 누른 뒤 적용된 카드로 **자동 스크롤**할지, 강조 표시만 할지

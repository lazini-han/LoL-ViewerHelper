## 3. 요구사항 1: 포지션 필터

### 3-1. 포지션은 정해져 있는가? → **대체로 그렇다**

Riot 공식 데이터(`champion-rune-recommendations.json`, **2026-08-16 갱신**)를 전수 조사한 결과:

| 사용 가능 포지션 수 | 챔피언 수 | 비율 |
|---------------------|-----------|------|
| 1개 (완전 고정) | 85종 | 49% |
| 2개 | 61종 | 35% |
| 3개 | 25종 | 15% |
| 4개 | 2종 (말파이트, 판테온) | 1% |

- **84%가 2개 이하** → 필터로서 충분히 유용
- 173종 **전부** 포지션 데이터 보유 (누락 0)
- 포지션별 분포도 균형적: 정글 65 / 미드 64 / 탑 62 / 서포터 58 / 원딜 41

### 3-2. 데이터 출처 비교

| 출처 | 프로 데이터 | 최신성 | 브라우저 직접 호출 | 판정 |
|------|-------------|--------|--------------------|------|
| **CDragon `champion-rune-recommendations.json`** | ✕ (솔랭 기준) | ◎ 2026-08-16 | ◎ CORS 허용 | **채택** |
| Meraki Analytics (`positions` 필드) | ✕ | ✕ 2024년(14.20) 이후 중단, 유나라/로크 없음 | ✕ CORS 헤더 없음 | 탈락 |
| Leaguepedia `Special:CargoExport` | ◎ 실제 프로 픽 | ◎ | △ 브라우저 직접 호출은 부적합 | **검증용으로 사용** |
| Oracle's Elixir CSV | ◎ 실제 프로 픽 | ○ | ✕ 수동 CSV 다운로드 | 탈락 |
| Data Dragon | ✕ (포지션 정보 자체가 없음) | - | ◎ | 해당 없음 |

> **주의**: 채택 데이터는 프로 전용이 아니라 **Riot 클라이언트의 추천 포지션**입니다.
> 실제 프로 픽과 얼마나 일치하는지는 아래 3-3에서 실측 검증했습니다.

### 3-3. 프로 경기 실제 픽과의 일치성 검증 (실측)

Leaguepedia `Special:CargoExport`로 **2026년 프로 경기 전체 픽 데이터**를 받아 대조했습니다.
(`api.php`는 rate limit에 막히지만 `Special:CargoExport` 경로는 정상 동작)

| 항목 | 전체 프로 리그 | LCK |
|------|----------------|-----|
| 분석한 총 픽 수 | 99,870 | 11,490 |
| **픽 단위 일치율** | **98.8%** | **99.1%** |
| 20픽 이상 사용된 챔피언 | 156종 | 85종 |
| 그중 프로 주 포지션이 Riot 목록에 포함 | **154종 (98.7%)** | **84종 (98.8%)** |
| 챔피언 이름 매칭 실패 | 0건 | 0건 |

**→ 결론: 거의 일치합니다.** 불일치는 전체 픽의 1.2%(LCK 0.9%)에 불과합니다.

#### 주 포지션이 어긋난 챔피언 (전체 2종)

| 챔피언 | 프로 실제 주 포지션 | Riot 데이터 | 비고 |
|--------|---------------------|-------------|------|
| **렉사이** | **탑** (전체 픽의 60%, LCK는 100%) | 정글만 | 변칙이 아닌 **주력 픽** → 보정 필요 |
| 모르가나 | 미드 (31%) | 서포터만 | LCK에서는 일치, 전체 리그에서만 어긋남 |

#### Riot 목록에 없는데 프로에서 나온 조합 (전체 픽의 1.2%)

```
갈리오 탑 114픽(12%)   렉사이 탑 112픽(60%)   트위스티드 페이트 탑 71픽(21%)
트리스타나 탑 45픽(11%)  탈리야 원딜 45픽(4%)    쉔 정글 42픽(6%)
사일러스 탑 37픽(6%)    쉬바나 탑 37픽(33%)
```

렉사이·쉬바나를 빼면 대부분 해당 챔피언 픽의 4~21% 수준이라 **변칙픽 범주**입니다.

#### 반대 방향 노이즈 (Riot 목록엔 있는데 프로에서 안 쓰임)

- Riot 포지션 조합 290개 중 프로 픽 0회는 **9개(3%)** — 이블린 정글, 피들스틱 탑, 아이번 서포터,
  카타리나 원딜, 말파이트 서포터, 티모 서포터, 베이가 서포터, 칼리스타 탑, 퀸 정글
- 필터에 약간의 노이즈가 섞이지만 실사용에 지장 없는 수준

### 3-4. 구현 방안 비교

| 방안 | 난이도 | 위험성 | 비고 |
|------|--------|--------|------|
| **A. 오프라인으로 `champions.json`에 `positions` 필드 추가** | 낮음 | 낮음 | +4KB (52KB → 56KB) |
| B. 런타임에 CDragon에서 매번 조회 | 낮음 | 중간 | 포지션 4KB 얻자고 **508KB** 다운로드 |
| C. 프로 경기 데이터를 수동 집계 | 높음 | 중간 | 정확하지만 시즌마다 수작업 |

**권장: A** — 이 프로젝트는 이미 `champions.json`을 수동 관리 목록으로 쓰고 있어 일관됩니다.
패치로 포지션이 바뀌면 재생성 스크립트를 한 번 돌리면 됩니다.

### 3-5. UI 방안

- **`assets/icons/`에 Top/Jungle/Mid/ADC/Support.webp가 이미 있어** 신규 에셋 불필요
- 기존 검색 필터와 AND 조합 (`renderChampions()` 한 곳만 수정)

## 4. 요구사항 2: 초보자용 챔피언 요약

### 4-1. 사용 가능한 데이터

CDragon `v1/champions/{id}.json` (**앱이 스킬 비디오 때문에 이미 호출·캐싱 중 → 추가 네트워크 비용 0**):

| 필드 | 내용 | 커버리지 |
|------|------|----------|
| `playstyleInfo` | 딜 / 체력 / 군중제어 / 기동성 / 지원 (각 1~3) | 173/173 |
| `tacticalInfo` | 난이도(1~3), 물리/마법, 근접/원거리 | 173/173 |
| `championTagInfo` | 특징 태그 2개 | 170/173 |

### 4-2. 자동 생성 결과 예시 (실제 데이터로 검증)

```
가렌   | 탑          | 난이도 쉬움   | 단단함 · 지속 딜        | 딜2 체력3 CC1 기동1 지원1
애쉬   | 원딜/서포터  | 난이도 쉬움   | 평타 중심 · 군중 제어    | 딜2 체력1 CC3 기동1 지원2
아리   | 미드        | 난이도 보통   | 기동성 · 폭발 딜        | 딜3 체력1 CC2 기동3 지원1
리 신  | 정글        | 난이도 어려움 | 기동성 · 1대1 강함      | 딜3 체력2 CC2 기동3 지원1
쓰레쉬 | 서포터      | 난이도 어려움 | 이니시에이팅 · 아군 보호 | 딜1 체력2 CC3 기동1 지원3
```

- **번역해야 할 고유 태그는 19개뿐** (군중 제어, 기동성, 폭발 딜, 1대1 강함, 광역 공격, 평타 중심,
  아군 보호, 파고들기, 이니시에이팅, 단단함, 후반 캐리, 긴 사거리, 자체 회복, 지속 딜, 은신,
  근접 마법사, 소환수, 지속 피해, 변신)
- 난이도 분포: 쉬움 53 / 보통 72 / 어려움 48

### 4-3. 구현 방안 비교

| 방안 | 난이도 | 품질 | 유지보수 | 커버리지 |
|------|--------|------|----------|----------|
| **A. 데이터 기반 자동 생성** | 낮음 | 중 | 없음 (자동) | 173/173 |
| B. 챔피언별 한글 요약 수작업 | 매우 높음 | 최상 | 패치마다 재검토 | 작성한 만큼 |
| C. A 먼저 + 주요 챔피언부터 B 보강 | 중간 | 상 | 점진적 | 173/173 |

- **A 단독**: "무엇을 잘하는 챔피언인지"는 알려주지만 "**어떻게** 하는지"는 못 알려줌
  (예: 가렌이 Q로 돌진해 침묵시킨다는 건 표현 불가)
- **B 단독**: 173개 한글 요약 작성은 이번 작업 범위를 크게 초과
- **C**: A의 자동 요약을 기본값으로 깔고, `championSummary` 필드가 있는 챔피언은 그 문장을 우선 표시

**사용자 결정: 방안 A (자동 생성만)** — 2026-08-31 확정.
수작업 요약(B)과 하이브리드(C)는 채택하지 않습니다.

### 4-4. 표시 위치 제안

- 경기 화면 챔피언 상세 패널 상단 (역할 표시 바로 아래) — 기존 스킬 목록 위
- 능력치 5종은 막대 그래프로 시각화 (1~3 스케일)

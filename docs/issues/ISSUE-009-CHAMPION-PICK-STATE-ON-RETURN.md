# ISSUE-009: 챔피언 픽 페이지 재진입 시 포지션 필터 표시 불일치

작성일: 2026-10-26
상태: **구현 완료** (2026-10-26, A안)

---

## 1. 문제

포지션 필터를 고른 뒤 다른 페이지에 갔다가 챔피언 픽 페이지로 돌아오면, 필터 버튼은 선택되지 않은 상태로 보이는데 챔피언 목록은 그 포지션으로 걸러져 있다.

## 2. 원인

- `js/app.js` 에서 `ChampionPickPage` 객체를 **앱 시작 시 한 번만** 만들고, 페이지에 올 때마다 같은 객체의 `render()` 를 다시 부른다.
- 필터 상태 `this.positionFilter` 는 객체에 남아 있어 `renderChampions()` 가 그대로 걸러낸다.
- 그런데 `createPositionFilter()` 는 버튼을 새로 만들 때 `position-filter__btn--active` 클래스를 붙이지 않는다. 활성 표시는 버튼을 누를 때(`togglePositionFilter()`)만 갱신된다.

### 같은 원인의 숨은 문제: 탭 선택 상태

- 모바일 탭 배치용 `this.tapSelectedChampion` 도 객체에 남는다.
- 챔피언을 탭해 선택한 채 다른 페이지로 갔다 오면, 안내 바(`탭하여 배치하세요`)는 사라졌지만 선택은 살아 있다.
- 이때 빈 슬롯이나 밴 칸을 탭하면 **예전에 고른 챔피언이 들어가고**, 채워진 슬롯을 탭하면 비우는 대신 덮어쓴다.

(검색어는 렌더링 때 입력창과 목록이 모두 비워져 문제 없음)

## 3. 개선 방안

| 안 | 내용 | 장단점 |
|----|------|--------|
| **A. 필터 유지 + 버튼 표시 맞춤 (추천)** | 돌아와도 고른 포지션을 유지하고, 렌더링 때 해당 버튼을 활성 표시 | 경기 중 같은 포지션을 계속 보는 흐름이 끊기지 않음. 수정 1곳 |
| B. 돌아오면 필터 초기화 | `render()` 에서 `positionFilter` 를 비움 | 항상 전체 목록에서 시작. 매번 다시 골라야 함 |
| C. 필터를 저장소에 저장 | localStorage 에 저장해 새로고침 후에도 유지 | 이 정도 기능에 비해 과함 |

**탭 선택**은 어느 안이든 `render()` 에서 초기화한다. 화면에 보이지 않는 선택이 남아 있으면 안 된다.

## 4. 변경 파일 (예상)

| 파일 | 변경 |
|------|------|
| `js/pages/ChampionPickPage.js` | `createPositionFilter()` 에서 활성 클래스 반영, `render()` 에서 탭 선택 초기화 |
| `CHANGELOG.md` | Fixed 기록 |

## 5. 확인 방법

- 필터 선택 → 다른 페이지 → 복귀: 버튼 활성 표시와 목록이 일치
- 챔피언 탭 선택 → 다른 페이지 → 복귀 → 빈 슬롯 탭: 아무것도 들어가지 않음
- 콘솔 오류, 글자 대비 확인

## 6. 구현 결과

- A안으로 구현: `createPositionFilter()` 가 유지된 필터를 활성 표시, `render()` 에서 `tapSelectedChampion` 초기화
- 헤드리스 Chrome 확인: 미드 선택(173→62개) → 팀 설정 → 복귀 시 미드 버튼 활성·62개 유지, 해제 시 173개. 탭 선택 후 복귀해 빈 슬롯을 탭해도 챔피언이 들어가지 않음. 콘솔 오류 없음
- 수정 전 코드로 같은 테스트를 돌려 복귀 후 활성 버튼이 없음을 재현함
